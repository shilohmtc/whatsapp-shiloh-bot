# Shiloh OS — Public Booking Phase 1.2 Visual Boundary

Date: 2026-08-17

Phase 1.2 is a presentation-only enhancement to `/book`.

- The canonical Shiloh production service catalogue remains the only service source of truth.
- The catalogue remains visually dominant; clinic imagery is decorative and confined to wide desktop side space.
- Side imagery is hidden below the wide-desktop breakpoint so tablet and mobile booking flow stays uncluttered.
- No service, price, duration, practitioner eligibility, availability, appointment, schedule, conflict, Calendar or WhatsApp booking semantics are changed.
- Availability remains confirmed only inside the existing Shiloh booking flow.
