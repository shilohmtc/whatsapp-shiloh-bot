# Mobile admin UX

Shiloh's WhatsApp admin console is mobile-first.

Design rules:
- Prefer numbered guided choices over command syntax.
- Keep screens short and scannable.
- Ask for one piece of information at a time.
- Keep technical/power-user commands as optional shortcuts, not the primary UI.
- Always provide a simple Back/Menu route.
- Scheduling changes must remain permission-checked and audited.
